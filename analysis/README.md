# 로그 분석

```powershell
python -m streamlit run app.py
```

`로그 분석` 탭은 소켓 서버 없이 사용할 수 있습니다. `로그 열기 · 변경`에서 폴더/파일 경로를 입력하거나 CSV·NPZ를 업로드한 뒤 로그를 선택하세요. 경로는 Streamlit이 실행되는 PC 기준이며, 하위 폴더도 검색합니다. 이름이 같은 CSV·NPZ는 자동으로 함께 읽습니다.

`오버레이 영상` 탭에서 선택한 NPZ와 MP4를 합성할 수 있습니다. MP4 경로를 입력하거나 업로드하고 `오버레이 영상 만들기`를 누르세요. 같은 폴더의 같은 이름 MP4는 자동으로 경로를 채웁니다. 원본 해상도·FPS로 전체 영상을 만들며 스켈레톤, 우측의 큰 좌우 반복 횟수, 측정값과 진행률 바를 표시합니다. 얼굴 관절과 음성은 포함하지 않습니다.

결과는 기본 `analysis/outputs/overlay_videos/`에 저장하며 저장 폴더와 로그 시간 보정을 선택할 수 있습니다. 원본 파일과 기존 결과를 덮어쓰지 않습니다. 저장된 `video_frame_idx`가 있으면 영상 프레임에 맞추고, 없으면 로그 시간과 영상 시작 시각을 사용합니다. 측정 샘플 사이에는 직전 결과를 표시하며, 1초 넘게 샘플이 없으면 관절 표시를 멈춥니다. 카운트는 다시 계산하지 않습니다.

합성 중간 파일과 업로드한 입력 영상도 선택한 결과 폴더에서 처리합니다. Windows Temp 폴더는 사용하지 않으며, 처리가 끝나면 중간 파일만 정리합니다. 오류가 발생해도 영상 파일을 닫은 뒤 정리합니다.

새 NPZ에는 프레임별 횟수·상태·진행률도 저장합니다. 과거 NPZ는 같은 세션의 CSV를 함께 읽으면 보완합니다. 기록이 부족한 횟수는 `--`로 표시합니다. FFmpeg가 PATH에 있으면 H.264로 변환해 브라우저에서 재생하며, 없으면 MPEG-4 MP4를 다운로드해 플레이어에서 확인합니다.

## 화면 구성

- **측정 분석**: 해당 동작의 실제 저장 측정값, 시작·목표 기준, 카운트 시점, 판정 상태와 추적 품질.
- **관절 비교**: 동작에 필요한 관절을 자동 선택하고 unnorm/norm 좌표를 나란히 비교.
- **상세 데이터**: 원본 표, 임의 열의 추가 그래프, 통계, 세션 요약과 CSV 다운로드.

처음에는 전체 구간과 양쪽을 표시합니다. `구간 · 표시 설정`에서 구간, 좌우, 기준선과 카운트 표시를 바꿉니다. 파일 경로, 관절 세부 설정, 반복 표, 추가 진단 등은 필요할 때 펼칩니다.

## 동작별 측정값

- `ANGLE`: 설정된 세 관절의 각도(°).
- `COORDINATE`: 설정 관절의 축 방향 위치 또는 기준 관절 대비 좌표 차이. **정규화 좌표(무차원)**로 표시합니다.
- `LENGTH`: 두 관절 사이 거리. **정규화 거리(무차원)**로 표시합니다. 두 방식 모두 몸통 길이를 1로 맞춘 좌표를 사용하지만 실제 길이 단위가 아닙니다.
- `RELATIVE_DISPLACEMENT`: 휴식 기준 길이 대비 관절 이동량. 그래프·분석 통계에서는 %로 표시하며, 원본 로그의 비율 값은 변경하지 않습니다.

새 로그는 `use_normalization`에 따라 좌표·거리 단위를 표시합니다. `false`는 몸통 정규화 없이 영상 높이를 기준으로 축 단위만 맞춘 좌표입니다. 상대 이동량의 `PEAK_REVERSAL` 방식은 상승 후 하강을 확인해 카운트하며 절대 휴식 위치로의 복귀를 요구하지 않습니다. 저점 + 최소 상승량, 피크 − 최소 하강량은 움직이는 내부 판정 위치이며 설정 threshold와 구분합니다.

설정 threshold는 메인 측정 그래프에서 고정선으로 표시하며 명시적인 `threshold_version` 변경 때만 계단식으로 바뀝니다. 상대 이동량의 움직이는 저점·피크 판정 위치는 **내부 저점·피크 판정 위치 보기**를 펼쳐 확인합니다. 초기 설정은 NPZ의 저장 설정을 우선하고, 없으면 버전별 최초 CSV 값임을 화면에 표시합니다. 과거 로그에 자동으로 바뀐 내부 기준이 있으면 안내하며, 해당 원본 열은 상세 데이터에 그대로 보존합니다.

CSV의 측정 방식과 NPZ 세션 요약을 우선 사용합니다. 핵심 관절/이동 축 등은 로그에 기록된 설정을 우선하고, 없으면 현재 `configs/exercise_kpt_config_coco.json`을 참고합니다. 과거 로그에 설정이 없고 현재 설정이 바뀌었다면 자동 선택된 관절이 당시와 다를 수 있으므로 `측정 방식 · 핵심 관절`에서 출처를 확인하세요.

이두 굴곡은 손목, 어깨 운동은 어깨·팔꿈치·손목, 현재 무릎 신전은 무릎·발목을 기본 선택합니다. `관절 · 좌표 설정`에서 선택을 바꿀 수 있습니다.

## 카운트와 진단

세로 점선은 저장된 카운트 시점입니다. 마우스로 시간, 좌우, 횟수, 프레임을 확인합니다. CSV의 `*_count_updated`가 우선이며, 플래그가 없는 과거 CSV만 누적 횟수 증가 프레임을 사용합니다. 첫 행의 횟수만으로 이벤트를 새로 만들지는 않습니다.

`카운트 기록`에는 발생 시간과 카운트 사이의 최솟값·최댓값·변화 폭·간격을 표시합니다. 간격은 **카운트 확정 시점 사이의 시간**이며 실제 동작 지속시간을 추정한 값이 아닙니다. 첫 카운트에는 이전 간격이 없습니다. 각각 CSV로 내려받을 수 있습니다.

`추적·판정 상태`에서는 상태 시간축, 유효 측정 비율, 변화 폭, 가림 비율, 핵심 관절 신뢰도를 확인합니다. `기준값 변화 · 추가 진단`을 펼치면 기준 위치/길이, 기준 확보 비율, 분위수, 활성 기준 이상 연속 유지 시간, 긴 기록 간격을 볼 수 있습니다. 유지 시간 계산은 0.2초 초과 간격과 기준 변경을 끊어서 계산하며, 서버 카운트를 재판정하지는 않습니다.

상대 이동량에서 카운트가 없는 경우, 데이터가 뒷받침할 때만 활성 기준 미도달·유지 시간 부족·기준 초과 시 복귀 대기 상태 등의 관찰을 안내합니다. 진단 수치는 원인을 확정하는 판정이 아닙니다.

## 좌표 비교

- **unnorm · 영상 비율**: x/영상 너비, y/영상 높이. 아래쪽이 +Y.
- **unnorm · 픽셀**: 픽셀 좌표 또는 영상 크기가 있는 NPZ에서 선택 가능.
- **norm**: 서버 PoseNormalizer 사용. 골반 중심=0, 몸통 길이=1, 위쪽이 +Y.

좌표 변환과 신뢰도 필터는 관절 그래프에만 적용합니다. 원본 측정값·카운트는 재계산하지 않습니다. norm에 필요한 골반/어깨 관절이 불확실하면 그래프가 비거나 끊길 수 있습니다. CSV와 NPZ의 시간축이 다르면 관절 그래프에 카운트를 겹치지 않습니다.

CSV만 있어도 측정 분석을 사용할 수 있습니다. NPZ만 있으면 저장된 측정값·관절 좌표·요약을 읽지만 정확한 카운트 발생 시간은 CSV가 필요합니다. `video/side/joint`가 있는 통합 좌표 CSV도 상세 데이터의 추가 시계열에서 확인할 수 있습니다. 시간 열이 없는 CSV는 행 번호로 표시합니다.

원본 파일은 읽기만 하며, 다운로드는 별도의 CSV입니다.

## 코드

- `log_reader.py`: CSV·NPZ, 좌표 변환, 카운트 이벤트 읽기.
- `metrics.py`: 측정 방식/핵심 관절 식별, 반복별 변화, 진단 수치.
- `ui.py`: Streamlit 분석 화면.
